# Rainbow Tail prototype

依存関係のない Canvas ゲームです。ES Modulesを使用しているため、ローカルHTTPサーバーから`index.html`を開いてください。

`index.js`がCanvas生成と初回実行を担当し、ゲーム処理は`src`フォルダ内に機能別で分割しています。

## ビルド

```sh
npm install
npm run build
```

productionビルドではwebpackがJavaScriptをminifyし、提出用ファイル一式を`dist`フォルダへ出力します。ビルド完了時に`dist`の合計バイト数も表示されます。

提出用ZIPの生成と13KB制限の検査は、次のコマンドで実行します。

```sh
npm run build:zip
```

productionビルド後、`dist`の中身だけを最高圧縮率で`submission.zip`へ格納します。ZIPサイズが13,312 bytesを超えた場合は、コマンドがエラー終了します。

- `←` / `→` または `A` / `D`: 30度旋回
- スマートフォンでは画面の左半分 / 右半分をタップ: 30度旋回
- `Space`または画面下部の`RAINBOW`ボタン: 基準5秒で虹を発動
- `Space` / `Enter` または画面タップ: ゲームオーバー後にリスタート

虹の発動中に軌跡が過去の軌跡と交差して輪を作った際、その内側に灰色の雲があれば取得し、使用した軌跡を消費します。雲のない空の輪は得点なしで虹が終了しますが、ゲームは続行します。制限時間内に囲みを作らなかった場合も、虹は軌跡ごと消えます。効果終了後は手動で再発動できます。

灰色雲の囲みに成功すると、虹が自動的に再発動してコンボ状態になります。基準時間は7秒で、その時間内に再び灰色雲を囲むと得点が2倍になり、成功するたびに4倍、8倍、16倍と倍増します。成功するたびにコンボ虹の残り時間が再設定されます。時間切れになるか、灰色雲のない空の輪を作るとコンボは終了します。

速度が上がっても虹で描ける距離がほぼ一定になるよう、手動虹の5秒とコンボ虹の7秒は現在速度に反比例して短縮されます。表示時間は`max(2秒, 基準時間 × 初速 ÷ 現在速度)`で計算します。

カメラは進行方向にだけスクロールし、一度通過したマップへ戻ることはできません。画面の左右端または下端へ移動するとゲームオーバーになります。

ユニコーンは初速112px/秒で、スコアを100点獲得するごとに速度が1px/秒上がります。時間経過だけでは加速せず、最高速度は350px/秒です。初速、最高速度、加速に必要なスコアは`src/const.js`の`PLAYER_SPEED`、`PLAYER_MAX_SPEED`、`SCORE_PER_SPEED_INCREASE`で調整できます。

空からは色を奪う黒い雫が落下します。黒い雫にユニコーンが接触した場合もゲームオーバーになります。出現間隔、大きさ、落下速度は`src/const.js`で調整できます。

ゲームオーバー時のスコアはブラウザのlocalStorageへ保存されます。ランキングはスコアの高い順に上位3件まで保持し、ゲームオーバー画面に表示します。スコアが0の場合はランキングへ追加しません。

輪の完成判定では中心線同士の交差に加え、虹の描画幅を考慮した22px以内の近接も接続として扱います。描画幅と判定距離は`RAINBOW_WIDTH`から共通設定されます。

## スコア計算

虹で雲を囲んだときの獲得スコアは、次の式で計算します。

```text
獲得スコア = 囲んだ灰色雲の数 × √囲んだ面積 × 虹の長さ倍率 × コンボ倍率
```

虹の長さ倍率は、輪を構成する軌跡の座標数から計算します。

```text
虹の長さ倍率 = 1 + min(4, 軌跡の座標数 / 90)
```

倍率の上限は5倍です。現在は実際の移動距離ではなく、保存された軌跡の座標数を虹の長さとして使用しています。最終的な獲得スコアは四捨五入した整数になり、現在の合計スコアへ加算されます。

コンボ倍率は最初の囲みでは1倍です。以降、速度に応じたコンボ時間内に囲みを連続して成功させるたびに`2^コンボレベル`で増加します。

すでにカラフルになった雲は得点対象になりません。輪の内側に灰色雲が1つもなかった場合は、得点なしで虹とコンボが終了します。画面の`TRAIL`は直前の囲みに使った虹の長さ倍率、`COMBO`は次の囲みに適用されるコンボ倍率です。
